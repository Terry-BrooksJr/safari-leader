Portfolio Project — Not a Real Zoo

Safari Leader is a portfolio demonstration project by Terry A. Brooks, Jr. and is not intended for production use with real childcare data. It showcases full-stack software engineering practices including encrypted data handling, role-based access control, and operational monitoring. No actual animals were let loose in the making of this platform.
